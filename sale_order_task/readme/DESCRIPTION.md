Configure project and task templates on service products. Confirming a sale order
creates one project for the order, merges the template tasks into it and mirrors
selected tasks into a second project.

- Product option *Project & Task Templates* (`service_tracking`) with a project
  template or a single task template.
- Mirror tasks: a task with a *Mirror Project* gets a copy in that project; stage and
  status are synchronized as configured (none, original, mirror, both).
- Stage links (*Project > Configuration > Link Mirror Task Stages*) translate the
  stages between the original and the mirror project.
